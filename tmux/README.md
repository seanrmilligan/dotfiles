# TMUX

## Commands

- rename window `CTRL` + `b`, `,`
- move active pane to a new window `CTRL` + `b`, `!`
- split screen top/bottom `CTRL` + `b`, `"`
- split screen left/right `CTRL` + `b`, `%`
- create new window `CTRL` + `b`, `c`
- switch to window by name `CTRL` + `b`, `'`
- switch to window by number `CTRL` + `b`, `<number>`
